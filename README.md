## How I work · 我的工作方式

**Understand the problem → build a small version → test it → improve it.**  
**理解问题 → 做出小版本 → 验证效果 → 持续改进。**

I care about readable code, clear ownership, and debugging with evidence. I enjoy documenting what went wrong as much as sharing what worked.

我重视可读的代码、清晰的职责和有依据的排查。除了分享做成了什么，也愿意记录哪里踩过坑、后来如何解决。
